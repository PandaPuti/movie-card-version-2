# Movie Cards Pro v2

A sleek, responsive web page showcasing a collection of favorite movies with an elegant dark theme inspired by Netflix.

## Description

This project displays movie cards for a curated selection of classic films. Each card features the movie poster, plot summary, rating, release year, genre, director, and main cast members. The design uses a modern dark theme with red accents for a cinematic feel.

## Features

- **Dark Theme**: Netflix-inspired dark background with red highlights
- **Responsive Design**: Movie cards adapt to different screen sizes
- **Hover Effects**: Cards lift and glow on hover for interactive feedback
- **Movie Details**: Comprehensive information including plot, rating, year, genre, director, and cast
- **Clean Layout**: Centered, flexible grid layout for optimal viewing

## Movies Included

1. The Shawshank Redemption (1994)
2. The Godfather (1972)
3. The Dark Knight (2008)
4. The Godfather Part II (1974)
5. 12 Angry Men (1957)

## How to Use

1. Download or clone the repository
2. Open `movie-cards-pro-v2.html` in any modern web browser
3. View the movie collection

## Technologies Used

- HTML5
- CSS3 (inline styles)

## Customization

To add more movies or modify the design:

- Edit the HTML structure to add new movie cards
- Modify the CSS styles for different themes or layouts
- Replace image URLs with your preferred movie posters

## Browser Compatibility

Works in all modern browsers that support CSS3 features like flexbox and transitions.
